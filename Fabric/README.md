# Microsoft Fabric Projects

End-to-end data analytics pipelines built with Microsoft Fabric — covering data ingestion, cleaning, warehousing, SQL analytics, and Power BI reporting.

## Projects

| Project | Description | Live Dashboard |
|---------|-------------|---------------|
| [Swiggy Food Analytics](./Swiggy-Project/) | End-to-end Fabric pipeline on 197K Swiggy orders — Lakehouse ingestion → SQL cleaning → Data Warehouse star schema → Power BI dashboard analysing ₹53M in sales across restaurants, locations, and food types | [View](https://app.fabric.microsoft.com/links/j5vF1cNmT6?ctid=ba71b931-9eff-463c-9362-cf330d222326&pbi_source=linkShare) |
| [Finance Analytics](./Finanace-Domain-Project/) | SQL-based finance analytics on 50K transactions — fraud detection, revenue segmentation, and 27 business KPIs using Fabric + Dataflow Gen2 + Warehouse *(dashboard coming soon)* | — |

## Skills Demonstrated

- Microsoft Fabric Workspace setup and management
- Lakehouse — raw data ingestion and file organisation
- SQL — data cleaning, validation, and referential integrity checks
- Data Warehouse — star schema design and table modelling
- Dataflow Gen2 — ETL/ELT transformations
- Power BI Semantic Model — relationships, measures, KPIs
- Power BI Reports — interactive multi-page dashboards
